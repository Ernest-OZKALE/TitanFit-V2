# 🏋️ Titan Architect - Monorepo Hub

Bienvenue sur le dépôt central de l'écosystème **Titan Architect**. Ce projet regroupe des solutions avancées de fitness et de nutrition intégrant l'IA, le suivi biométrique et la gamification.

## 📁 Structure du Projet

L'écosystème est organisé pour une clarté maximale et une maintenance évolutive :

### 🚀 [Applications (apps/)](./apps)
- **[Web-App](./apps/web-app)** : Application web Next.js 16 (Turbopack) offrant une expérience immersive de coaching.
- **[Mobile-App](./apps/mobile-app)** & **Local Mobile Versions** : Solutions mobiles pour un suivi en déplacement.

### 🏛️ [Infrastructure & Base de données (infrastructure/)](./infrastructure)
- Schémas SQL complets pour Supabase (Auth, AI, Progress, Social, Gamification).
- Scripts de migration et d'optimisation.

### 📚 [Documentation Technique (docs/)](./docs)
- **[Audits de Sécurité](./docs/Titan_Master_Audit.md)** : Rapport complet sur l'intégrité du code.
- **[Roadmap V2](./docs/TITAN_ROADMAP_V2.md)** : Visions et développements futurs.
- **[Guides de Déploiement](./docs/DEPLOYMENT_GUIDE_FR.md)** : Instructions détaillées pour Vercel et l'environnement local.

---

## 🛠️ Stack Technologique Globale
- **Frontend** : Next.js 16 (React 19), Tailwind CSS, Framer Motion.
- **Backend** : Supabase (PostgreSQL, Realtime, Edge Functions).
- **Intelligence Artificielle** : Intégrations Google Gemini & Hugging Face.
- **Mobile** : React Native / Expo.
