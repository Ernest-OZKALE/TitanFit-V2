# 📱 TitanFit - Version Mobile (Expo) 👋

Bienvenue dans la version mobile de l'écosystème Titan Architect. Ce projet est développé avec **Expo** et **React Native** pour offrir une expérience fluide sur iOS et Android.

## 🚀 Démarrage Rapide

### 1. Installer les dépendances
```bash
npm install
```

### 2. Lancer l'application
```bash
npx expo start
```

### 3. Visualisation
Une fois le serveur lancé, vous pouvez :
- Scanner le QR Code avec l'application **Expo Go**.
- Appuyer sur `a` pour l'émulateur Android.
- Appuyer sur `i` pour le simulateur iOS.

## 📁 Structure du Projet
- **`app/`** : Contient tous les écrans et la logique de navigation (File-based routing).
- **`components/`** : Composants React Native réutilisables.
- **`constants/`** : Thèmes, couleurs et configurations globales.

## 📚 En savoir plus
Pour explorer les possibilités d'Expo, consultez la [documentation officielle](https://docs.expo.dev/).
